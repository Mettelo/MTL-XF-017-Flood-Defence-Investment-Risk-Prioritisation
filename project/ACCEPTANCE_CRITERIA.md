# Agreed Acceptance Criteria

1. **AC1:** Every scheme in the curated model has a documented source identifier or explicit generated-key rule.
2. **AC2:** Total funding in the curated model reconciles to the selected source scope after quantified exclusions.
3. **AC3:** The project explicitly separates programme/funding indicators from engineering flood-risk measures.
4. **AC4:** Any prioritisation score lists all factors and weights and includes at least three scenario weightings.
5. **AC5:** Schemes with insufficient critical fields are flagged rather than silently scored.
6. **AC6:** Geographic maps use only source-supported or documented derived locations.
7. **AC7:** At least five dashboard totals reconcile to the curated scheme table.
8. **AC8:** A reviewer can rebuild the scheme portfolio and prioritisation scenarios from the approved frozen source without undocumented manual edits.

## Sign-off Rule
Repository files existing is not enough. The panel must verify these criteria from evidence.

## Evidence Mapping
Map every criterion to requirement(s), artefact(s), test/reconciliation evidence, owner and status.
